# HelpDesk — Frontend

![Deploy](https://github.com/fO-r-Ze/HW_Netology_JavaScript_Helpdesk-Frontend/actions/workflows/deploy.yml/badge.svg?branch=main)
[GitHub Pages](https://fO-r-Ze.github.io/HW_Netology_JavaScript_Helpdesk-Frontend/)

Фронтенд для HelpDesk — сервиса управления заявками. Работает с REST API бэкенда через **fetch**.

Исходное задание — в [TASK.md](./TASK.md).

## Возможности

- Загрузка списка тикетов с сервера.
- Создание нового тикета (модальное окно, поля «Краткое описание» и «Подробное описание»).
- Редактирование тикета (✎) — тот же модальный редактор с предзаполненными полями.
- Удаление тикета (✕) с подтверждением в модальном окне.
- Отметка о выполнении (чекбокс) — обновление статуса на сервере.
- Просмотр деталей: клик по телу тикета (не по кнопкам) разворачивает подробное описание, которое подгружается отдельным запросом `ticketById`.
- Обновление списка после каждой мутации (create/update/delete).
- Индикатор загрузки в виде текста под списком.

## Стек

- JavaScript (ES2020+) без фреймворков
- `fetch` API для HTTP-запросов
- Webpack 5 + Babel + CSS-loader
- ESLint (flat config)
- npm (без yarn.lock)

### Как это работает
- Фронтенд (React/Webpack) развернут на GitHub Pages.
- Бэкенд (Node.js) развернут на облачной платформе Render (URL: `https://helpdesk-backend-keys.onrender.com`).

**⚠️ Важное примечание для проверяющего:**
Бэкенд использует бесплатный тариф Render, поэтому сервер «засыпает» после 15 минут бездействия. Если вы открыли страницу и список тикетов не загружается — подождите **30–40 секунд** (сервер просыпается) и обновите страницу. Дальше всё будет работать быстро.
